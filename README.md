# 🎮 Johan's Quest: Pixel Realm

Un videojuego plataformas 2D en tiempo real desarrollado en HTML5 Canvas y JavaScript puro.

## 🚀 Características
- **Personaje jugable:** Johancito (con animaciones de caminata y carrera en ambas direcciones).
- **Enemigos:** Slime slime verde animado con comportamientos de rebote.
- **Entorno:** Bloques de tierra, piedra e ítems recolectables.
- **Gráficos:** Pixel art creado a medida.

## 🛠️ Tecnologías
- HTML5 Canvas
- CSS3
- JavaScript (Vanilla)
