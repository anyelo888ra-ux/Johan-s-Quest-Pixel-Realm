# 🎮 Johan's Quest: Pixel Realm

Un juego de plataformas 2D desarrollado con HTML5 Canvas y JavaScript puro.

## 🚀 Características
* **Personaje principal:** Johancito (sprites de caminata y carrera).
* **Enemigos:** Slime verde animado.
* **Mundo:** Bloques de tierra, piedra e ítems recolectables en pixel art.

## 🛠️ Tecnologías
* HTML5 Canvas
* CSS3
* JavaScript (Vanilla)
